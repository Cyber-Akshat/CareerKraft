# Accessibility assets

`OpenDyslexic-Regular.woff2` is the unmodified regular OpenDyslexic web font
from the author's archived upstream repository:

https://github.com/antijingoist/opendyslexic/blob/main/compiled/OpenDyslexic-Regular.woff2

and license are retained in `OFL.txt`.

The SVG arrow and text cursors were created for CareerKraft. They use a
black shape with a white outline for visibility against light and dark
backgrounds. Use these native-pixel CSS cursor hotspots:

| File | Size | Hotspot |
| --- | --- | --- |
| `cursor-small.svg` | 16 by 24 | 1 1 |
| `cursor-large.svg` | 40 by 56 | 2 2 |
| `text-small.svg` | 16 by 24 | 8 12 |
| `text-large.svg` | 32 by 48 | 16 24 |
