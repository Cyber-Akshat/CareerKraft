## Shared generation prompt

Use case: stylized-concept. Asset type: a single square profile-avatar illustration for the CareerKraft account character chooser. Primary request: [subject below]. Style: polished original soft 3D clay toy illustration, rounded tactile shapes, subtle matte texture, simple confident silhouette, appealing to teenagers and adults, expressive friendly personality. Composition: one character only, centered front-facing head-and-shoulders portrait filling 78 percent of the square with generous safe margins for rounded avatar cropping; all ears, leaves or antennae fully inside the frame. Scene/backdrop: clean solid [background below] background, soft studio light and very subtle contact shadow. Palette: restrained pastel lilac, mint, warm peach and cream accents coherent with a lavender app. Clear contrast between face and background; face remains recognizable at 48 pixels. No text, no letters, no names, no logos, no watermark, no frame, no collage, no other objects or characters.

Images use an opaque background (`transparent_background: false`).
Project copies are resized to 512 × 512 PNG for avatar delivery; the generated source images remain in the tool's original output location.
